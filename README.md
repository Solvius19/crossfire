# Crossfire
A competitive trivia game to play with friends.

## About this project

This project utilizes the OpenTDB database in order to allow players to engage in the turn-based trivia game with their friends.

Key features:
- Local multiplayer and turn-based system
- Features a variety of attack options in order to make the game more challenging

## Built with
- Java 26
- Maven
- Jackson-Core (for reading JSON)

## Getting started
To play, simply clone the project to your local computer, and you should be ready to go!
```bash
git clone https://github.com/Solvius19/crossfire.git
```
